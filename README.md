# The Nexment Project

Organization-wide files, assets, and GitHub configuration for [The Nexment Project](https://nexment.in).

This repository contains shared resources used across Nexment's GitHub organization.

## Structure

- `assets/` — Nexment logos and visual assets
- `profile/` — GitHub organization profile
- `ISSUE_TEMPLATE/` — Shared issue templates
- `CODE_OF_CONDUCT.md` — Community standards
- `CONTRIBUTING.md` — Contribution guidelines
- `SECURITY.md` — Security reporting guidelines

Individual projects maintain their own source code, documentation, and licensing.
